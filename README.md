# MiniGram v5.1 — 탭 분리 UI

v5 기능은 그대로 유지하면서 화면을 인스타그램처럼 탭 구조로 분리한 버전입니다.

## 탭

- 🏠 홈: 오늘의 질문 + 가벼운 시작
- 📸 추억: 추억 리턴 + 공동 추억 폴더
- ⏳ 캡슐: 타임캡슐 현황 + 만들기
- 💬 피드: 글 / 사진 / 댓글 / 작성기
- 👤 내정보: 로그인 / 프로필

이제 한 화면에 모든 카드가 동시에 나오지 않습니다.

## 적용

v5 SQL을 아직 실행하지 않았다면 먼저 `migration_v5_memories.sql` 실행.

그 다음 이 ZIP의 `index.html`로 기존 GitHub 파일을 덮어쓰기 → Commit → Push.

v5 SQL을 이미 실행했다면 SQL은 다시 실행할 필요 없습니다.
