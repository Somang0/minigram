# MiniGram v4.2 — 댓글 입력 UI 정리

이번 수정은 DB/SQL 변경 없이 프론트 UI만 정리했습니다.

## 변경

로그아웃 상태:
- 위쪽에 `닉네임` + `비밀번호` 두 칸
- 아래쪽에 공통 `댓글 달기...` 입력 + 게시 버튼

로그인 상태:
- 닉네임/비밀번호 칸은 아예 표시하지 않음
- `댓글 달기...` 입력 + 게시 버튼만 표시

기존의 `비로그인 댓글 달기...` 문구를 `댓글 달기...`로 통일해서
세 번째 비로그인 전용 입력처럼 보이던 혼란을 없앴습니다.

## 적용

SQL 다시 실행할 필요 없음.

이 ZIP의 `index.html`만 기존 프로젝트에 덮어쓰기 → Commit → Push.
