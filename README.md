# MiniGram v5 — Memories / Time Capsule SNS

기존 피드 중심 MiniGram을 친구들끼리 쓰는 **추억 SNS**로 바꾼 버전입니다.

## v5 핵심 컨셉

> 인스타에 올리기엔 별것 아니고, 단톡방에서는 묻혀버리는 우리끼리의 기록.

메인에 피드만 두지 않고:

- 🔥 오늘의 질문
- ⏳ 타임캡슐
- 🕰 추억 리턴
- 📸 공동 추억 폴더
- 💬 기존 피드

를 같이 보여줍니다.

## 기능

### 오늘의 질문
매일 질문이 하나 자동으로 바뀝니다.

예:
- 오늘 제일 어이없었던 일은?
- 우리끼리만 아는 레전드 사건 하나?
- 1년 뒤 우리에게 하고 싶은 말?

`답변 남기기`를 누르면 작성기가 오늘답변 모드로 바뀝니다.

### 타임캡슐
게시물을 작성하면서 미래 날짜/시간을 설정합니다.

설정 시간이 되기 전에는 다른 사람에게 내용/사진/댓글이 숨겨지고
공개 시간이 지나면 일반 추억처럼 열립니다.

로그인 사용자는 자기 타임캡슐을 작성한 뒤 피드에서 확인할 수 있습니다.
비로그인 타임캡슐은 공개 전에는 다른 사람에게 내용이 가려집니다.

### 추억 리턴
7일 이상 지난 일반/추억 글을 메인 카드에서 다시 보여줍니다.
새 DB 테이블 없이 기존 기록을 재활용합니다.

### 공동 추억 폴더
게시물을 `공동추억` 모드로 작성하고 이름을 붙입니다.

예:
- 대부도 2026
- 민수 생일
- 제주도 여행
- 새해 모임

여러 사람이 같은 이름으로 올리면
메인의 칩을 눌러 해당 추억만 모아볼 수 있습니다.

## 기존 기능 유지

- 회원가입/로그인
- 이메일 인증 OFF 상태 사용 가능
- 비로그인 글: 닉네임 + 비밀번호
- 비로그인 글 수정/삭제
- 로그인 본인 글 수정/삭제
- 댓글
- 비로그인 댓글 + 비밀번호 수정/삭제
- 사진 업로드
- 다크모드

## 적용 순서

1. v2 / v3 / v4가 이미 적용되어 있어야 합니다.
2. Supabase SQL Editor에서 `migration_v5_memories.sql` 전체 실행
3. 이 ZIP의 `index.html`로 GitHub의 기존 `index.html` 덮어쓰기
4. Commit + Push
5. GitHub Pages 새로고침

기존 회원, 글, 댓글, 사진은 삭제하지 않습니다.
